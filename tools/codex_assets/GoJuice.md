# GoJuice (budget 1k tris, 1024 textures)
Game use: Go-juice, a combat stimulant: three small rugged injector vials in a scuffed grey polymer clip tray, ~0.14 x 0.09 x 0.06 m. Each vial is a thick clear tube (~1.5 x 8 cm) of glowing-looking orange-red fluid (colour only, no emissive needed; use low roughness and a bright colour) with a black rubber plunger cap and a steel needle guard, a yellow-black hazard stripe band, no text.
Separate parts: `Body`.
Axis: small-item convention (origin at bottom centre).
