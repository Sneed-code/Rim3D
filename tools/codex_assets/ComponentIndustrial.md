# ComponentIndustrial (budget 3k tris, 1024 textures)
Game use: ComponentIndustrial, the common "component" item colonists haul, buy and craft with. A compact
mechanical/electrical module about 0.16 x 0.12 x 0.08 m: a cast metal housing with cooling fins, an
exposed green circuit board edge with a few chips, a small gear and shaft sticking out one end, a
bundle of coloured wires and a connector plug, a stamped batch number plate. Should read clearly from a
few metres away as "useful machine part". Also add a second object `ComponentStack`: five of them in a
loose believable pile (for a stack on the floor), each mesh joined, ~6k tris total allowed for the stack.
Axis: small-item convention (origin at bottom centre).
