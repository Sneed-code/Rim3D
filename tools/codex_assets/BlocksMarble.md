# BlocksMarble (budget 2.5k tris, 2048 textures)
Game use: marble blocks, a building resource, a stack item lying on the ground. A neat small stack of six to eight cut marble blocks (each ~0.20 x 0.10 x 0.08 m, crisply sawn faces with faint saw lines, a few chipped corners showing sugary crystals), two layers crosswise plus one leaning, ~0.42 x 0.30 x 0.20 m overall. White to pale grey with soft grey veins that run on across each block's faces, a light film of stone dust and a grubby handprint. Each block really modelled with bevels, small gaps between; sawn faces a little smoother (G ~0.5), not metallic.
Separate parts: `Body`.
Axis: small-item convention (origin at bottom centre).
