# Codex asset briefs

One brief per asset Rim3D needs that has no good free model (checked Fab free 2026-11-19), made with the
Codex CLI on sneed's PC. `_common.md` is the shared part (formats, axes, quality bar); `<Name>.md` is the
asset. `run_codex_assets.sh` runs them (see its header). Results live outside Git in
`Rim3D_Codex\<Name>\` (GLB, textures, previews, README); importing them is a later Unreal step.

Found free on Fab instead (not made here): frag grenade ("MK2 Frag Grenade (rigged)", "Grenade F1"),
single-tube rocket launcher for the doomsday launcher ("PBR Game Ready RPG Launcher", "RPG7"), solar panels
("60-Cell Solar Panel with Stand", "Solar Panel Array Rack"), wind turbine ("Animated Wind Turbine"),
survival meal pack ("Military Ration Meal Pouch").

Batches: 1 (the first 15, done 2026-11-19), 2 (20 briefs added 2026-11-19: hydroponics to the hive), 3 (20 briefs
added 2026-11-20: VitalsMonitor, FermentingBarrel, Hopper, Cooler, PassiveCooler, FloodLight, Autodoor, Telescope,
TubeTelevision, PokerTable, HorseshoesPin, AnimalSleepingBox, AnimalBed, the monosword, plasma sword, zeushammer
and breach axe, the high-explosive mortar shell, the advanced component and the bionic arm; the last five hit
the Codex usage limit and rerun with batch 4), 4 (20 briefs added 2026-11-20, not run yet as the Codex limit
resets 2026-11-22 14:38: revolver, machine pistol, heavy SMG, chain shotgun, LMG, sniper rifle, minigun, charge
rifle, recurve bow, EMP grenade, flatscreen TV, hatchery, vent, power switch, double bed, ship computer core,
ship sensor cluster, spike trap, industrial medicine, bionic leg). Picked from defs
that still draw box parts; melee weapons that already have models (knife, club, gladius, mace, longsword,
spear) were left out.
