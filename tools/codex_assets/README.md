# Codex asset briefs

One brief per asset Rim3D needs that has no good free model (checked Fab free 2026-11-19), made with the
Codex CLI on sneed's PC. `_common.md` is the shared part (formats, axes, quality bar); `<Name>.md` is the
asset. `run_codex_assets.sh` runs them (see its header). Results live outside Git in
`Rim3D_Codex\<Name>\` (GLB, textures, previews, README); importing them is a later Unreal step.

Found free on Fab instead (not made here): frag grenade ("MK2 Frag Grenade (rigged)", "Grenade F1"),
single-tube rocket launcher for the doomsday launcher ("PBR Game Ready RPG Launcher", "RPG7"), solar panels
("60-Cell Solar Panel with Stand", "Solar Panel Array Rack"), wind turbine ("Animated Wind Turbine"),
survival meal pack ("Military Ration Meal Pouch").
