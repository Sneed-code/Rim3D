# Gun_Greatbow (budget 8k tris, 2048 textures)
Game use: Gun_Greatbow, a medieval longbow / greatbow, ~1.8 m tip to tip, ~1.4 kg. A long D-section stave of
honey-coloured wood with darker heartwood on the belly, horn nocks at the tips, a thick linen-wrapped grip
with a leather arrow rest, a waxed linen string (braced, not drawn). Polished from use, a few scratches, string
fuzz.
Separate parts: `Body`, `String`. Empties `StringTop`, `StringBottom`, `Nock`.
Axis: hand-weapon convention, held upright like Gun_ShortBow (back towards +X, limbs along Z).
