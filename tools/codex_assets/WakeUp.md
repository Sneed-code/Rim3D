# WakeUp (budget 1.5k tris, 1024 textures)
Game use: wake-up, a factory-made stimulant pill that cuts the need for sleep, a stack item. A small blister strip of six glossy oval yellow capsules (two pressed out, foil torn) and one loose capsule beside it, ~0.10 x 0.05 x 0.012 m. Silver foil back with a generic printed grid pattern, clear plastic bubbles, a small yellow stripe stencil (no text). Light scuffs.
Separate parts: `Body`.
Axis: small-item convention (origin at bottom centre).
