# OrbitalTradeBeacon (budget 8k tris, 1024 textures + emissive)
Game use: OrbitalTradeBeacon, a 1 x 1 m powered beacon that marks trade goods for passing ships, ~1.3 m
tall. A short sturdy post on a weighted base with a small dish/antenna array and a pulsing amber beacon lamp on
top (emissive mask), a weatherproof electronics box with a keypad and status lights, a cable to the ground,
reflective hazard stripes, scuffed paint, red tropical dust.
Separate parts: `Body`, `Dish` (turns about Z; pivot on the post axis). Empty `Lamp` at the beacon light.
Axis: building convention, the keypad towards -Y.
