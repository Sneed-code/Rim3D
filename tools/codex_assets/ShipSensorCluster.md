# ShipSensorCluster (budget 14k tris, 2048 textures)
Game use: ShipSensorCluster, the sensor array of the escape starship, 2 x 2 cells, ~2.0 m tall. A squat
armoured base with a turntable ring, a mast carrying a dish antenna (~1 m), a cluster of smaller sensor
pods and a whip antenna, a red beacon light on top, cable runs. Off-white and grey composite with scuffed
edges, dirt at the base, a hand-welded repair patch.
Separate parts: `Base`, `Dish` (pivot = yaw axis on the vertical line through the origin, so it can
turn). Empty `Beacon` at the light. Emissive map for the beacon.
Axis: building convention, the dish facing -Y at rest.
