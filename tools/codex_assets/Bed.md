# Bed (budget 8k tris, 2048 textures)
Game use: Bed, a single bed, 1 x 2 cells (~0.95 m wide, ~2.0 m long). A solid wooden frame with a plain headboard, a
mattress, a fitted sheet, a rumpled woven blanket folded back, one pillow. Homely frontier furniture to match the
double bed: hand-planed wood with tool marks, faded cloth. The frame's wood takes a stuff tint, so keep it fairly
neutral.
Separate parts: `Frame` (wood), `Bedding`. Empty `Sleeper1` at the sleeping spot. Head end towards +Y, foot towards -Y.
Axis: building convention, the front (working side) facing -Y.
